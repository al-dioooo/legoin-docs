# legoin-docs

Documentation for Legoin: team guidelines, the decision log and the API contract. Code lives in [legoin-web](https://github.com/al-dioooo/legoin-web) (the web app) and [legoin-ml](https://github.com/al-dioooo/legoin-ml) (the models).

| Folder | Contents |
| --- | --- |
| [guidelines/](guidelines) | How we commit, branch, and open pull requests |
| [decisions/](decisions) | Architecture Decision Records (ADRs) |
| [api/contract.md](api/contract.md) | The API contract between legoin-web and the backend: endpoints, shapes, errors and rules |

## Contributing

This repository follows its own guidelines: work on a branch, write [Conventional Commits](https://www.conventionalcommits.org/) (usually `docs: ...`), and merge through a pull request.
